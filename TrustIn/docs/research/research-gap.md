# TrustIn research-gap positioning

TrustIn does not claim that DID, VC, NFT, RBAC, ZK, dynamic NFTs, usage control or blockchain audit are individually new.

The project analysis classified those items as established or already researched building blocks. The proposed gap is the integrated relationship:

**identity + ownership + policy + current asset integrity + authorization evidence**

with an explicit state change:

**integrity failure → quarantine → privileged operations blocked**

See the root README and the SIH submission materials for the documented research basis.
