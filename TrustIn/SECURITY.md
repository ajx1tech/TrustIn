# Security Policy

TrustIn is currently in the **development phase**.

## Reporting

Please do not report security vulnerabilities in public GitHub issues. For a private report, use the repository's configured security contact once the project is publicly registered.

## Current security scope

The architecture is designed around:

- least-privilege roles
- smart-contract authorization
- DID/VC verification
- asset integrity commitments
- explicit quarantine states
- cryptographically linked authorization receipts
- off-chain storage for sensitive data
- static analysis and invariant testing planned for contracts

## Important

The included `index.html` is a **static demonstration**. It does not provide production-grade authentication, key custody, cryptographic proof generation, or blockchain settlement.
